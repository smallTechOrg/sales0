Paste li_at cookie (server fallback)

Read this first. Use this only when Chrome cannot be opened on this machine (a server / VPS).

  • The li_at cookie IS your LinkedIn login. Anyone who has it can act as you: treat it like a password and never share it.
  • Automating LinkedIn can breach LinkedIn's Terms of Service; your account may be restricted.
  • LinkedIn is quick to flag logins from datacentre IP addresses, so this is riskier than the Chrome window on your own computer.
  • The cookie is stored encrypted in the database with SALES0_SECRET_KEY, which must be set on a server. If that key changes you must paste the cookie again.
