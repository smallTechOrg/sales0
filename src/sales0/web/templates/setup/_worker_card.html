How to start the worker
  1. On the laptop, in the sales0 checkout: SALES0_WORKER_SERVER_URL={{ public_url or "https://<this app's URL>" }} and SALES0_WORKER_TOKEN=<the sales0-worker-token secret> in .env.
  2. Log in to LinkedIn once: uv run sales0 worker --connect (a Chrome window opens; finish 2FA).
  3. Start it: uv run sales0 worker and leave it running. Queue a run on the Runs page.
